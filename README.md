# Judy

Judy is an AI-powered conversational weather assistant.

Instead of just showing temperature and rain probability,
Judy provides practical advice based on real-world conditions.

Examples:
• What should I wear today?
• Is it too windy for a hat?
• Will the roads be slippery?
• Should I bring an umbrella?

Judy analyzes:
- Temperature
- Wind speed
- Feels-like temperature
- Rain probability
- Humidity

And provides human-like advice through chat or voice.

Example interaction:

User:
"Do I need a jacket today?"

Judy:
"It’s around 13°C, but strong winds will make it feel colder.
A light jacket would be a good idea."

To build a Siri-like weather assistant that provides
practical real-life advice rather than raw weather data.
